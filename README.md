Welcome to the Sturdevant-Smithy Website. Run by a brother duo who hand-make all their metal crafts. This website's purpose is so that the customer can view what we offers/have done before and see if one interests them, or if it helps them come up with a knife or other item they might want us to smith or make. Ending with the customer sending us an email detailing their order with an address for shipping. Then will review the order and see if it's something we can do. be it cooking tools for the everyday man or carving knifes.
